# This is a US patented system with below features.

## **Hub Features**
A device mounted in classroom, above the doors of every room (to indicate the current event status) and some along the hallways. This device has custom electronics and firmware.【教室内安装的一种设备，通常安装在每个房间门的上方（用于指示当前事件状态），并在走廊位置也会安装部分设备。该设备采用定制的电子硬件和固件。】
❖ Uses wireless technology, independent of Wi-Fi. 【使用独立于 Wi-Fi 的无线通信技术。】
❖ Has LEDS that light RED, YELLOW, BLUE or GREEN. Color codes can be changed to suit an organization’s requirements. 【设备配有 LED 指示灯，可显示 红 / 黄 / 蓝 / 绿 四种颜色；颜色含义可根据组织或机构的需求进行自定义调整。】
Need 4 colors for LEDs that are bright enough to guide first responders as they race through the Hallways.【需要 4 种足够明亮的 LED 指示颜色，以便在紧急情况下，引导第一响应人员快速穿过走廊。】
❖ Same HW but three uses: RoomHub, DoorHub and HallwayHub. When configuring a Hub, it needs to be correctly designated by its function below:【相同的硬件，但有三种使用场景：RoomHub、DoorHub 和 HallwayHub。在配置 Hub 时，需要根据以下功能正确指定其类型：】

**RoomHub** – Installed in the room/class, can be ceiling mounted. Illuminates RED during Code Red, illuminates Green when “all clear” is triggered from Dashboard, no illumination when under normal situation or when “Clear all statuses” is issued from the Dashboard. 【RoomHub —— 安装在房间 / 教室内，可安装在天花板上。在 Code Red 状态下显示 红色；当从 Dashboard 触发 “all clear（解除警报）” 时显示 绿色；在正常情况下或当从 Dashboard 执行 “Clear all statuses（清除所有状态）” 时，不显示任何灯光。】

**DoorHub** - Installed right outside the room/class , above or beside door, can be wall mounted. Illuminates RED during Code Red, illuminates Green when “all clear” is triggered from Dashboard, illuminates Blue when medical emergency is triggered from that class/room, illuminates Yellow when admin alert request is triggered from that class/room, no illumination when under normal situation or when “Clear all statuses” is issued from the Dashboard. 【DoorHub —— 安装在房间 / 教室外部，位于门的上方或旁侧，可壁挂安装。在 Code Red 状态下显示 红色；当从 Dashboard 触发 “all clear（解除警报）” 时显示 绿色；当该房间 / 教室触发 医疗紧急事件 时显示 蓝色；当该房间 / 教室触发 管理员警报请求 时显示 黄色；在正常情况下或当从 Dashboard 执行 “Clear all statuses（清除所有状态）” 时，不显示任何灯光。】

**HallwayHub**- Installed along hallways, can be ceiling mounted. Illuminates RED during Code Red, illuminates Green when “all clear” is triggered from Dashboard, no illumination when under normal situation or when “Clear all statuses” is issued from the Dashboard. Will remain RED as long as “All Clear” or “Clear all statuses” are NOT triggered from the Dashboard. 【HallwayHub —— 安装在走廊区域，可安装在天花板上。在 Code Red 状态下显示 红色；当从 Dashboard 触发 “all clear（解除警报）” 时显示 绿色；在正常情况下或当从 Dashboard 执行 “Clear all statuses（清除所有状态）” 时，不显示任何灯光。只要 Dashboard 未触发 “All Clear” 或 “Clear all statuses”，设备将始终保持 红色 显示状态。】

❖ Battery powered. Long life to avoid swapping. Minimum 3 years, replaceable. The longer the better.
Note: To conserve battery power, the Hubs may not light continuously in an emergency. Rather, they can be made to flash every xx Seconds. This applies to code Red, Medical Emergency or Admin request alert. The pulse cycle for the flashing should be adjustable in firmware. Small solar panel and rechargeable battery will lengthen duration and make it maintenance free. 
The current product has a buzzer that is loud enough. The system is independent of the Intercom system but can be integrated with the intercom. 
Note: To save battery power, the Hubs can “buzz” for about 30 – 60 seconds and then stop the sound.
This is the current 60 seconds buzz that the Hubs make on code Red.

【电池供电。为减少更换频率，需具备较长的电池使用寿命，最低 3 年，电池可更换，续航时间越长越好。
说明： 为了节省电量，在紧急情况下 Hub 不一定持续常亮，而是可以设置为每隔 xx 秒闪烁一次。该机制适用于 Code Red、医疗紧急事件 以及 管理员警报请求。闪烁的脉冲周期需可在固件中进行调整。若配合小型太阳能板 + 可充电电池，可进一步延长使用时间，实现近乎免维护。
当前产品配备音量足够大的蜂鸣器。该系统独立于对讲系统（Intercom）运行，但可与对讲系统进行集成。
说明： 为节省电池电量，Hub 的蜂鸣提示可在触发后持续约 30–60 秒，随后自动停止。
目前产品在 Code Red 状态下的蜂鸣时长为 60 秒。】

❖ HallwayHub to have a camera that becomes active only in Code Red situations (future feature).
This is not a must have right now. Will be added for future releases. 【HallwayHub 预留摄像头功能：在 Code Red 情况下才会激活摄像头（未来功能）。该功能目前非必须，计划在后续版本中加入。】
❖ Can be installed outside the building and also at playgrounds. IP66/IP67 waterproof and ability to withstand extreme temperatures. Should be able to receive signal there.【可安装在建筑物外部及操场等室外区域，需具备 IP66 / IP67 防水等级，并能承受极端温度环境；在这些位置也应能够正常接收信号。】
❖ Need Over-The-Air (OTA) firmware updates without the need to pull the Hub down.【支持 OTA（空中升级）固件更新，无需将 Hub 拆卸或取下即可完成升级。】
❖ FCC certified or certifiable RF modules.【使用 已通过 FCC 认证或具备可认证条件的射频模块。】
❖ Will use off-the-shelf housing that can accommodate the PCB, Battery, LEDS etc.【将采用现成的外壳，能够容纳 PCB、电池、LED 等组件。】

## **Badge Features**
A device is worn by staff to stay connected with the alert system. This device has custom electronics and firmware. 【一种由工作人员佩戴、用于与报警系统保持连接的设备。该设备采用定制的电子硬件和固件。】
❖ Four (4) buttons: Red, Green, Blue and Yellow. These colors may change to suit an organization’s requirements.【配备 4 个按键：红色、绿色、蓝色和黄色；按键颜色可根据组织需求进行调整。】
❖ Buttons have time-delay to avoid false alerts (hold for 3-5 seconds).【按键具备延时触发机制，以避免误报警（需按住 3–5 秒 才会触发）。】
❖ Badge has LCD Screen. LCD remains unlit unless the is an alert or a tap on a button.【Badge 配备 LCD 屏幕，在无报警状态下保持不亮；当发生报警或轻触任意按键时，LCD 被唤醒显示。】
❖LCD can receive short messages from dashboard. (Broadcast or specific to a badge) 【LCD 可接收来自 Dashboard 的简短消息（可为广播消息或指定到某个 Badge）。】
❖ Tapping any button (short press) “wakes up” the LCD and shows the battery status【短按任意按键可唤醒 LCD，并显示电池电量状态。】
❖ Badge has 2 x LED lights that illuminate the desired color.Badge 【配备 2 个 LED 指示灯，用于显示所需的对应颜色。】
❖ When Red button is pressed, all the badges in the school beep, vibrate and illuminate red. All Hubs illuminate Red, and the Dashboard alert pops up showing “Code Red Alert, Bldg XY, Floor XX, Room XX). The Floor plan shows all rooms with solid Red and the source of Code Red “flashing Red”. It is critical that the alert is broadcast ASAP to make sure everyone is notified of the danger. Consider flooding or broadcast for code red alerts. It is critical that a code red alert is broadcast fast across the whole network【当按下红色按键时，学校内所有 Badge 都会 蜂鸣、振动并显示红色灯光；所有 Hub 将亮起 红色；同时 Dashboard 弹出报警提示，显示“Code Red Alert，建筑 XY，楼层 XX，房间 XX”。在 楼层平面图（Floor Plan） 上，所有房间以实心红色显示，而 Code Red 的触发源 则以 红色闪烁的方式标识。
⚠️ 关键要求：
警报必须 尽快（ASAP）进行广播，确保所有人员第一时间获知危险。
对于 Code Red 警报，应考虑采用 广播 / 泛洪（flooding / broadcast）机制。
Code Red 警报必须能够在整个网络中以极快速度传播，这是系统的核心要求。】

❖ When Blue button is pressed, only the administrator and nurse badges in the school beep,vibrate and illuminate Blue and their screen show “Medical Alert Room XX”. The DoorHub for that class illuminates Blue and the Dashboard alert pops up showing “Medical Alert, Bldg XY, Floor XX, Room XX). The Floor plan on Dashboard show room with blue indication. Consider multicast messaging to a group of devices. 【当按下蓝色按键时，学校内仅管理员和护士的 Badge 会 蜂鸣、振动并显示蓝色灯光，其屏幕显示 “Medical Alert Room XX”。对应教室的 DoorHub 将显示 蓝色，同时 Dashboard 弹出报警提示，显示 “Medical Alert，建筑 XY，楼层 XX，房间 XX”。Dashboard 的楼层平面图中，该房间将以 蓝色标识显示。应考虑采用 组播（multicast）消息 向一组设备发送通知。】
❖ When Yellow button is pressed, only the administrator badges in the school beep, vibrates and illuminate Yellow and their screen show “Admin Alert Room XX”. The DoorHub for that class illuminates Yellow and the Dashboard alert pops up showing “Admin Alert, Bldg XY, Floor XX, Room XX). The Floor plan on Dashboard shows room with yellow indication. Consider multicast messaging to a group of devices.【当按下黄色按键时，学校内仅管理员的 Badge 会 蜂鸣、振动并显示黄色灯光，其屏幕显示 “Admin Alert Room XX”。对应教室的 DoorHub 将显示 黄色，同时 Dashboard 弹出报警提示，显示 “Admin Alert，建筑 XY，楼层 XX，房间 XX”。Dashboard 的楼层平面图中，该房间将以 黄色标识显示。应考虑采用 组播（multicast）消息 向一组设备发送通知。】
❖ When Green button is pressed (only during a Code Red), the DoorHub for that class illuminate Green so first responders can skip that room and attend to rooms with Red.  The Floor plan on Dashboard shows room with Green indication.【当按下绿色按键时（仅在 Code Red 状态下），对应教室的 DoorHub 将显示 绿色，以便第一响应人员跳过该房间，优先处理仍显示 红色 的房间。
Dashboard 的楼层平面图中，该房间将以 绿色标识显示。】
Note – When a staff member presses the green during a code red, if they perceive danger, they can reactivate code red which does not reset the entire school but only for the staff/room is viewed on the dashboard as a new alert source. 【说明： 在 Code Red 状态下，当工作人员按下 绿色按键 后，如果其仍然感知到危险，可重新触发 Code Red。该操作不会重置整个学校的状态，而只会将该工作人员 / 房间在 Dashboard 上作为新的报警源进行显示。】
❖ The badges use rechargeable batteries that are charged with USB-C cables. Current badges hold charge for weeks/months.【Badge 使用可充电电池，通过 USB-C 线缆进行充电。当前版本的 Badge 在一次充电后可续航数周至数月。】
❖ Has charging indicator light that turns green when fully charged【配备充电指示灯，在充满电时会显示绿色。】
❖ Uses wireless technology to send status and to identify with a location (Hub)【使用无线技术发送状态信息，并用于识别其所属的位置（对应的 Hub）。】
This should be a configurable parameter; we would like an optimal setting so that a badge “registers” with a room when it comes in its vicinity. Maybe it can be configured to only “announce / register” new locations or when triggering an alert, otherwise remains “asleep”. The badge location on the dashboard is associated with a room.【这应作为可配置参数；我们希望有一个最优设置，使 Badge 在进入某个房间的覆盖范围时即可与该房间完成“注册/识别”。Badge 也可以被配置为仅在进入新的位置或触发报警时才进行“通告/注册”，其余时间保持休眠状态。在 Dashboard 上，Badge 的位置信息将与对应的房间关联显示。】
❖ Have a vibrator for tactile alert【配备震动马达，用于触觉提醒】
❖ Beeps when alert is received【在接收到报警时会发出蜂鸣声】
❖ When a badge is acting up press and hold Blue+Yellow buttons together.  Avoiding the Red button to eliminate false Red Alerts while resetting a badge.【当 Badge 出现异常时，可同时按住蓝色 + 黄色按键进行复位；在复位过程中需避免按下红色按键，以防误触发 Code Red 报警】
❖ When a reset does not work, a badge may need to be disable/re-enabled by pressing and holding Green+Blue buttons together.  Avoiding the Red button to minimize false Red Alerts while disabling/re-enabling a badge.【若复位无效，可同时按住绿色 + 蓝色按键进行禁用 / 重新启用 Badge；同样需避免按下红色按键，以尽量减少误触发 Code Red 报警】
❖ Uses wireless technology, independent of institution’s Wi-Fi【使用独立于机构 Wi-Fi 的无线通信技术】
❖ FCC certified / certifiable modules.【采用已通过 FCC 认证或具备可认证条件的无线模块】

## **Smart Dashboard**
This should be on the cloud server that monitors and manages events for the entire Emergency Alert network. See Abobe for details on how the Dashboard interacts/responds to devices and alerts.【该系统应部署在云服务器上，用于监控和管理整个紧急报警网络的事件。有关 Dashboard 如何与设备及报警进行交互和响应的详细说明，请参见上文。】
❖ Can run on desktop, phone or tablet【可在桌面端、手机或平板上运行】
❖ Floor plans of the school are uploaded by Building, Floor and Room number【可按建筑、楼层和房间号上传学校的楼层平面图】
❖ Shows number of connected badges and locations (by RoomHub association)【显示已连接的 Badge 数量及其位置（基于 RoomHub 的关联）】
❖ Shows badges that have not connected for a while, shows last time badge was connected【显示一段时间未连接的 Badge，并显示其最后一次连接时间】
❖ Shows the battery status of the Badges and Hubs【显示 Badge 和 Hub 的电池状态】
❖ Can send text messages or emails when badge battery level goes below 30%【当 Badge 电量低于 30% 时，可发送短信或电子邮件提醒】
❖ Shows room where alert is coming from (Code Red, Medical Emergency, or Admin Support request)【显示报警来源的房间（Code Red、医疗紧急事件或管理员支持请求）】
❖ Ability to send text messages to admin badges or cell phones【可向管理员 Badge 或手机发送短信】
❖ Used to Clear Code Blue【用于清除 Code Blue】
❖ Used to Clear Code Yellow【用于清除 Code Yellow】
❖ Used to set “All Clear” – Badges and Hubs will all illuminate Green【用于设置 “All Clear（解除警报）” —— 所有 Badge 和 Hub 将显示 绿色】
❖ Used to set “Clear All Statuses” – Go back to normal situation - Badges and Hubs will have no illumination【用于设置 “Clear All Statuses（清除所有状态）” —— 系统恢复到正常状态，Badge 和 Hub 均不显示灯光】

## **Gateway Features**
Gateway功能说明
A off-the-shelf device that communicates with Hubs and Badges within an area covered by RF signal range.【一种现成（现货）设备，在其 射频信号覆盖范围内 与 Hub 和 Badge 进行通信。】
❖ Data exchange is then relayed to the Dashboard 【数据交换随后将转发至 Dashboard】
❖ This device can be powered using regular power outlet (mains), USB-C and may also have backup battery in case of power failure【该设备可通过普通市电电源或 USB-C 供电，并可在断电情况下配备备用电池】
❖ Has connectivity to the Internet (to the cloud servers and middleware) – LAN/WiFI【具备互联网连接能力（连接至云服务器和中间件），支持 LAN / Wi-Fi】
❖ Has 4G/5G/LTE as backup connection to the Internet (to cloud servers)【具备 4G / 5G / LTE 作为互联网的备份连接（连接至云服务器）】
