
# LED 单线级联驱动协议说明文档

## 1. 硬件级联方式 (Chip Cascade Method)

LED灯珠通过 **DIN** (数据输入) 和 **DO** (数据输出) 接口进行硬件级联。
*   **信号流程**：MCU发送数据接入第一颗灯珠的 **DIN** 端 (D1信号)。
*   **整形转发**：灯珠内部具有自动整形转发电路，将接收到的数据延时处理后从 **DO** 端输出到下一级灯珠的 **DIN** 端。
*   **级联数据**：
    *   **D1**：MCU端发送的原始数据流。
    *   **D2, D3, D4...**：经过前级电路自动整形并转发出去的数据流。

## 2. 数据传输方式及通讯协议

数据采用**单线串行**的方式传输，每次传输包含一个完整的“数据刷新周期”。
*   **数据包结构**：一串连续的数据流由若干组 `24BIT` 数据组成（一个24BIT对应一颗灯珠）。
*   **帧结束 (RESET)**：在每帧数据传输结束（即完成所有灯珠的数据写入）后，总线必须保持一段低电平时间作为 **RESET CODE**，以触发灯珠锁存当前数据并刷新显示。
*   **RESET 时间要求**：
    *   时序图中标注：低电平时间必须 **> 80us**。
    *   技术注意事项说明：为确保余量，实际应用中建议低电平复位时间最小为 **100us**。

## 3. 24bit 数据帧结构 (Data Structure)

每一颗灯珠需要 24bit 的数据控制其颜色。

*   **位序**：**高位先发** (MSB First)。
*   **颜色顺序**：按照 **G -> R -> B** (绿-红-蓝) 的顺序排列数据。
*   **具体位分配**：
    *   **[G7 ... G0]**：绿通道，8位 (位 23 ~ 位 16)
    *   **[R7 ... R0]**：红通道，8位 (位 15 ~ 位 8)
    *   **[B7 ... B0]**：蓝通道，8位 (位 7 ~ 位 0)

> **举例发送纯红色 (最大亮度)**：`00000000 11111111 00000000`

## 4. 时序波形及电气参数

数据是通过 **高低电平持续时间** 的组合来区分数据位 `0` 和 `1` 的。

### 4.1 码型定义
*   **0码**：一个较短的高电平脉冲 (`T0H`)，随后跟随一个较长的低电平 (`T0L`)。
*   **1码**：一个较长的高电平脉冲 (`T1H`)，随后跟随一个较短的低电平 (`T1L`)。
*   **RESET码**：持续的低电平 (`Trst`)。

### 4.2 电气参数表 (Signal Transmission Definition)

| 参数 | 符号 (Symbol) | 最小值 (Min) | 典型值 (Typ) | 最大值 (Max) | 单位 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 输入 0 码高电平时间 | `Tin0h` | 0.20 | 0.295 | 0.35 | μs |
| 输入 1 码高电平时间 | `Tin1h` | 0.55 | 0.595 | 1.2 | μs |
| 输入 0 码低电平时间 | `T0L` | 0.55 | 0.595 | 1.2 | μs |
| 输入 1 码低电平时间 | `T1L` | 0.2 | 0.295 | 0.35 | μs |
| 0 码/1 码周期 | `T0 / T1` | 0.89 | - | - | μs |
| **RESET 码低电平时间** | `reset` | **80** | - | - | μs |

> *注：RESET码低电平时间最小值为80us（表中数据），但建议系统设计时采用100us以上的低电平以确保多灯串级联时的稳定性。*

## 5. 编程与控制注意事项

基于上述参数，在编写MCU控制程序时需注意以下逻辑：

1. **位判决逻辑 (Bit Decision)**：LED灯珠内部分辨“0”和“1”主要依据**高电平的持续时间**，判断逻辑如下：
   *   **逻辑 "0"**：高电平持续时间介于 **200ns ~ 410ns** 之间。
   *   **逻辑 "1"**：高电平持续时间介于 **640ns ~ 1000ns** 之间。
   *   *注：每次数据位的高电平结束后，低电平就代表该位传输完毕，准备接收下一位数据。*

2. **数据帧中断要求**：
   在一帧数据传输过程中（包括 24bit 和 24bit 之间、以及 bit 和 bit 之间）：
   *   总线上的低电平信号**中断时间不能超过 35μs**。
   *   如果超过 35μs，灯珠内部逻辑可能会误判为 **RESET 信号**，从而导致当前数据帧提前结束并刷新显示。
